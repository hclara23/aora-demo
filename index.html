Before you begin

What this preview proves.

Can I make a real booking or payment?

No. These demos use synthetic data and do not take payments. Real sign-in, billing and delivery must pass deployment checks before launch.

Is the clinical record shown here?

No. Clinical records are kept in a separate service. The wellness experience receives only the limited readiness information needed for the visit. That architecture is one technical control; it is not a HIPAA certification.

Will this be a native app?

The member experience shares React Native code across web, iOS and Android. Native release requires a supported build toolchain, device testing, completed privacy disclosures and App Store review.

What does it cost to operate?

Costs depend on the deployed resources, vendor usage and support work. The operator worksheet separates hosting, maintenance and initial build costs. Unknown figures remain unknown.
